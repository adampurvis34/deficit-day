# Portion Anchors

Everything needed to turn "what it looks like" into grams. Mass is the highest-leverage
input in the whole estimate, so spend the effort here.

---

## 1. Scale references in the frame

Find one of these before estimating anything. Listed best-first.

### Packaged objects (most reliable)

| Object | Dimension |
|---|---|
| Standard soda/beer can (12 oz / 355 mL) | 12.3 cm tall, 6.6 cm diameter |
| Slim can (12 oz) | 15.7 cm tall, 5.8 cm diameter |
| Half-litre water bottle | 20-21 cm tall, 6.4 cm diameter |
| Credit card | 8.6 × 5.4 cm |
| iPhone (standard, non-Max) | ~14.7 × 7.2 cm |
| AirPods case | 5.4 × 4.5 cm |

### Cutlery (very reliable, usually in frame)

| Object | Length |
|---|---|
| Dinner fork | 18-19 cm |
| Dinner knife | 21-23 cm |
| Dessert/salad fork | 15-16 cm |
| Tablespoon | 16-17 cm |
| Teaspoon | 14-15 cm |
| Chopsticks | 23-26 cm |

### Dishware

| Object | Diameter |
|---|---|
| Home dinner plate | 26-27 cm (10-10.5") |
| Restaurant dinner plate | 28-30 cm (11-12") |
| Salad / side plate | 18-20 cm (7-8") |
| Bread plate | 15-16 cm (6") |
| Cereal bowl | 15-16 cm, ~400 mL |
| Soup bowl | 18-20 cm, ~550 mL |
| Ramen / pho bowl | 20-23 cm, 900-1200 mL |
| Standard mug | ~350 mL |
| Pint glass | 470 mL |

**Restaurant plates are 1-3 cm wider than home plates.** Assuming a home plate for a
restaurant photo systematically underestimates every mass on it by 10-20%. When you can't
tell, and the setting reads as a restaurant, assume 28 cm.

## 2. Hand portions — calibrated for Adam

Standard hand-portion charts are built for an average adult. **Adam is 6'4", so his hand is
roughly 25-30% larger by volume than the charts assume.** Use the right column.

| Measure | Generic chart | **Adam (6'4")** | Typical use |
|---|---|---|---|
| Palm (no fingers), 2 cm thick | 85-110 g cooked protein | **130-150 g** | Meat, fish |
| Cupped hand | 40-60 g dry / ~125 g cooked grain | **~160-180 g cooked** | Rice, pasta, oats |
| Fist | ~240 mL (1 cup) | **~300-320 mL** | Vegetables, fruit |
| Thumb (whole) | 10-12 g | **~15 g** | Cheese, nut butter |
| Thumb tip | ~5 g (1 tsp) | **~7 g** | Oil, butter |

**Calibrate once and this gets much better.** Weigh a chicken breast that covers his palm,
and measure a cupped handful of cooked rice on a scale. Two data points, one time, and every
future hand-based estimate is anchored to his actual hand. Worth doing.

## 3. Volume → mass densities

When you can judge volume (a bowl is ⅔ full, rice covers a third of the plate 2 cm deep),
convert with these. Grams per US cup (240 mL) unless noted.

| Food | g / cup | Notes |
|---|---|---|
| Cooked white rice | 158 | Packed slightly less, ~145 |
| Cooked brown rice | 195 | |
| Cooked pasta | 140 | Penne/rotini; spaghetti ~125 |
| Cooked oatmeal | 234 | |
| Dry oats (rolled) | 80 | |
| Cooked quinoa | 185 | |
| Mashed potato | 210 | |
| Black/pinto beans, cooked | 172 | Drained |
| Lentils, cooked | 198 | |
| Chopped raw vegetables | 100-150 | Dense (carrot) high, leafy low |
| Leafy greens, raw, loose | 25-35 | Very low density — easy to overestimate |
| Leafy greens, packed | 60-70 | |
| Berries | 145 | |
| Chopped fruit | 150-165 | |
| Cottage cheese / Greek yogurt | 225-245 | |
| Shredded cheese | 110 | Loosely packed |
| Soup / stew, brothy | 245 | |
| Soup / stew, chunky | 250-260 | |
| Milk | 245 | |
| Nuts, whole | 130-145 | |
| Granola | 110-120 | |
| Cereal flakes | 30-40 | Very low density |

**Plate-area method** — for a flat-spread food on a 27 cm plate:
one quarter of the plate, 1.5 cm deep ≈ 140 mL. Multiply by the density above.
A "mound" that covers a third of the plate and stands 3-4 cm ≈ 250-300 mL.

## 5. Restaurant portion defaults

When a menu gives no weight, these are reasonable starting points for US restaurants:

| Item | Cooked weight |
|---|---|
| "Grilled chicken" entrée | 170-200 g |
| Steak, listed as 8 oz | 200-225 g cooked |
| Salmon fillet, entrée | 170-200 g |
| Burger patty, "1/3 lb" | 115-125 g cooked |
| Side of fries | 115-170 g |
| Side of rice | 180-250 g |
| Pasta entrée (cooked pasta alone) | 280-400 g |
| Burrito bowl rice scoop | 120-160 g |
| Burrito bowl protein scoop | 110-140 g |
| Pizza slice, 14" pie | 105-130 g |
| Sushi roll, 6-8 pieces | 170-220 g |

Restaurant portions have grown and menu photos understate them. When the plate looks
full, take the top of these ranges.

## 6. Cooked ↔ raw conversion

Cooking changes weight, not calories. The error here is systematic and large, so always
know which state you are in.

| Food | Raw → cooked | Cooked → raw |
|---|---|---|
| Chicken breast | × 0.73 | × 1.37 |
| Chicken thigh | × 0.75 | × 1.33 |
| Beef, ground | × 0.72 | × 1.39 |
| Beef, steak | × 0.72 | × 1.39 |
| Pork chop / tenderloin | × 0.72 | × 1.39 |
| Salmon / fatty fish | × 0.78 | × 1.28 |
| White fish | × 0.80 | × 1.25 |
| Shrimp | × 0.85 | × 1.18 |
| Bacon | × 0.42 | × 2.4 |
| White rice | × 2.8 | × 0.36 |
| Brown rice | × 2.6 | × 0.38 |
| Pasta | × 2.25 | × 0.44 |
| Couscous | × 2.6 | × 0.38 |
| Quinoa | × 2.9 | × 0.34 |
| Dried beans/lentils | × 2.4 | × 0.42 |
| Oats | × 3.0 | × 0.33 |
| Leafy greens (wilted) | × 0.25 | × 4.0 |

Meat yields vary ±5% with doneness. Well-done loses more; rare loses less.

A photo always shows **cooked** food. If the nutrient density you're using is a raw
figure, convert. Getting this backwards on rice is a 2.8× error.
